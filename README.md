# AI Personal Assistant 🤖

A simple AI personal assistant built with Flask, Python, JavaScript, and the OpenAI API.

### Features
- Ask questions and get AI-generated responses
- Summarize emails
- Simple and clean web interface

### Tech Stack
Python • Flask • OpenAI API • HTML • CSS • JavaScript

### Setup
Add your OpenAI API key to the `.env` file:

```env
OPENAI_API_KEY=your_api_key
```

### About
Built as a personal project to learn how to integrate AI APIs with a Flask web application.
